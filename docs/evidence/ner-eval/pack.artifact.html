Method — deterministic (free) NER cross-validation eval

Info

NER cross-validation (ner_cross_validation_enabled, default False) is a fully deterministic post-LLM pass: it boosts/penalizes annotation confidence using spaCy NER labels vs. a per-ontology branch affinity map, rejecting spans that fall below 0.20. Running the pipeline with llm=None gives a reproducible, /bin/bash ruler→NER→reconcile→resolve path that still exercises the flag. This pack reports that free comparison; the authoritative full-pipeline (LLM-sourced) comparison is spend-gated and queued to the QA portal.

Gold: 52 scored (oracle-verified) + 94 borderline (awaiting human verification), across 6 demo docs. Precision/recall are span-restricted over the labelled spans (correct for a sampled gold).
