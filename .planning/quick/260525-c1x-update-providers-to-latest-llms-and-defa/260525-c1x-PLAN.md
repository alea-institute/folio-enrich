# Quick Task 260525-c1x: Update providers to latest LLMs + default to Gemini 3 Flash

## Goal
1. Refresh each provider's model list with the most-recent models.
2. Make **Gemini 3 Flash** the app's default LLM, shown at the top of the provider + model lists.

## Findings (web-verified 2026-05-25)
- **OpenAI** latest: **GPT-5.5** (Apr 23, 2026). Registry stops at gpt-4.1/o3.
- **Anthropic** latest: **Claude Opus 4.7** (Apr 16, 2026). Registry has only up to Opus 4.6.
- **Google**: **Gemini 3.5 Flash** (GA) and **Gemini 3.1 Flash Lite** (~May 8) are newer than the
  registry's Gemini 3 line — but the user explicitly wants **Gemini 3 Flash** (`gemini-3-flash-preview`)
  as the default, so that is honored; the newer ones are added to the list.

> ⚠ Exact API IDs for the brand-new models (`gpt-5.5`, `gemini-3.5-flash`, `gemini-3.1-flash-lite`)
> are newer than the assistant's training cutoff. They use standard naming conventions and the app's
> live model-refresh (with an API key) corrects/supplements them. Worth a quick verify vs provider docs.

## How the UI orders things (verified)
- Provider dropdown: `GET /settings/providers` iterates `LLMProviderType`; frontend renders in response order.
- Model dropdown: `GET /settings/known-models` → `KNOWN_MODELS[provider]` rendered in list order; HTML
  selects the first option by default; `loadSettings()` then sets it to the saved `llm_model`.

## Tasks
1. **registry.py** — `KNOWN_MODELS`:
   - openai: append `gpt-5.5`.
   - anthropic: append `claude-opus-4-7`.
   - google: reorder so `gemini-3-flash-preview` (Gemini 3 Flash) is FIRST; append `gemini-3.1-flash-lite`, `gemini-3.5-flash`.
2. **anthropic_provider.py** — `_FALLBACK_MODELS`: add `claude-opus-4-7`.
3. **config.py** — `llm_provider = "google"`, `llm_model = "gemini-3-flash-preview"` (was `ollama` / `""`).
4. **settings.py** — `list_providers`: emit the configured default provider first so **Google Gemini** heads the dropdown.
5. **Tests** — run suite; update any assertion that pinned the default provider to `ollama`.

## Decisions / flags
- **Default flip Ollama → Google requires a Google API key.** Without one, the app degrades gracefully
  to the "symbolic AI only" banner. Flagged for the user.
- **`ollama_auto_manage` left `True`** (out of scope; harmless — no-ops where Ollama isn't installed).
- `DEFAULT_MODELS` for openai/anthropic left at their current mid-tier choices (not requested).

## Verify
- `GET /settings/providers` lists `google` first; `current.provider == "google"`, `current.model == "gemini-3-flash-preview"`.
- `KNOWN_MODELS[google][0].id == "gemini-3-flash-preview"`.
- Frontend: provider dropdown shows "Google Gemini" first; model dropdown shows "Gemini 3 Flash" first/selected.
- Backend test suite green.
