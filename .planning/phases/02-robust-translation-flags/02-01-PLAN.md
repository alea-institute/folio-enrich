## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FOLIO data -> innerHTML | Translation labels + locale strings come from FOLIO/backend data and are interpolated into pill markup rendered via innerHTML |
| vendor-time -> repo | The 12 flag SVG strings enter the codebase at author time (copied from flag-icons), never from runtime/user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering (XSS) | translation label injected into pill (makePill / flagMarkup) | mitigate | Keep `escapeHtml(label)` on the visible label and `escapeAttr(localeLabel(locale))` on aria-label/title — both helpers already exist at index.html:10309/10314 |
| T-02-02 | Tampering (XSS) | locale string in aria-label/title attribute | mitigate | localeLabel output is run through escapeAttr before interpolation into attributes (Pattern 1) |
| T-02-03 | Tampering | malicious markup inside a vendored flag SVG | accept | SVGs are an author-controlled allowlist (FLAG_SVG const) copied from a trusted MIT repo and manually reviewed (12 small strings); never sourced from runtime data |
| T-02-04 | Information disclosure / Denial (the live bug) | external image/CDN request for flags | mitigate | All flag pixels are inline `<svg>`; FLAG-02 token sweep asserts no http/url(/src=/<use in FLAG_SVG (Task 1 verify + Task 3 Network-tab check) |
| T-02-SC | Tampering | package installs | mitigate | No runtime packages installed (SVGs are vendored source text; svgo is dev-time-only and unused). Per RESEARCH Package Legitimacy Audit — no install gate needed |
</threat_model>
